# 의존성 업데이트 시각적 검증

점검일: 2026-11-17. 업데이트 전 `53772bad`의 원본 잠금 파일과 업데이트 후 `b0e31732`의 라이브러리·Storybook을 각각 빌드해 동일한 Chrome에서 비교했다.

## 결과

32개 화면과 9개 추가 상태를 2개 화면 크기·2개 테마에서 비교했다. 총 **164쌍(328장)의 픽셀 데이터가 모두 완전히 일치**했다. 화면 크기도 같았고, 최종 캡처에서 Storybook 렌더 오류와 브라우저 pageerror는 모두 0건이었다. 이 검증 범위에서 의존성 업데이트에 따른 레이아웃·색상·아이콘·차트의 시각적 회귀는 발견하지 못했다.

- 기존 Storybook 스토리 20개: 버튼 변형, 체크박스, 컨텍스트 메뉴, 그리드, 아이콘, 숫자 입력, 페이지네이션, 라디오, 선택기, 탭, 텍스트 입력, 토글, 트리 그리드, 윈도우, 로딩·메시지·메시지 박스·알림·진행률.
- 기존 데모 또는 고정 데이터로 만든 임시 화면 12개: 달력, 슬라이더, 트리, 스케줄러, 시간 선택기, 메뉴, 막대·원형·히트맵·산점도·선 차트, 날짜 선택기.
- 추가 상태 9개: 선택기 펼침, 윈도우 열기, 컨텍스트 메뉴 우클릭, 메시지·메시지 박스·알림 표시, 텍스트 입력/포커스, 토글 선택, 날짜 선택기 펼침.

추가로 Storybook 전체 문서 화면과 Controls도 확인했다. 버튼의 `type`을 `warning`에서 `primary`로 바꿨을 때 실제 배경색이 `rgb(255, 149, 0)`에서 `rgb(26, 106, 254)`로 바뀌었다. 문서 화면의 pageerror는 0건이었다.

## 발견하고 수정한 문제

기존 체크박스 스토리에 짝이 없는 `</EvCheckboxGroup>`가, 컨텍스트 메뉴 스토리에는 여분의 `</div>`가 있었다. 두 예제 모두 이전/이후 버전에서 Vue compiler-23 오류 화면을 띄웠다. 불필요한 닫는 태그를 제거해 두 예제를 정상 렌더링하도록 수정했다.

동일한 컴포넌트 출력을 비교하기 위해 비교용 이전 버전에도 위 두 태그 수정과 기존 아이콘 스토리 수정을 적용했다. 따라서 164쌍의 비교 결과는 동일한 스토리 입력에 대한 의존성 변경의 영향을 측정한다. 원래 예제의 오류와 수정 후 화면은 별도로 보존했다.

## 기존에 있던 시각적 제약

업데이트로 생기지 않은 문제도 확인했다.

- 390px 화면에서 아이콘 예제(516px), 선택기(421px), 달력 데모(609px), 트리 데모(420px), 시간 선택기(407px), 차트 예제(436~524px), 날짜 선택기(434px)에 가로 넘침이 있다. 괄호는 문서의 실제 scrollWidth이며 이전/이후 값이 동일하다. 예제의 고정 폭·차트 최소 폭·입력 영역 등을 반응형으로 정리하려면 별도 검토가 필요하다.
- `.dark` 클래스와 어두운 배경만 적용한 데모에서는 달력 헤더·데모 설명·차트 제목 일부의 대비가 낮고 날짜 팝업에 밝은 표면이 남는다. 이전 버전과 동일하다. 이 비교는 완전한 다크 테마 디자인이나 색상 대비 기준 충족을 보증하지 않는다.

이러한 기존 스타일 동작은 이번 의존성 업데이트에서 변경하지 않았다.

## 방법과 범위

- Chrome 157.0.8103.79, macOS, headless, deviceScaleFactor 1.
- 1280×900과 390×844의 뷰포트. 좁은 화면은 실제 모바일 기기/브라우저 테스트와 구분한다.
- 기본 테마와 HTML/body의 `.dark` 클래스 및 어두운 배경.
- 동일 날짜·난수·로케일(ko-KR)·시간대(Asia/Seoul), 폰트 로딩 완료 후 캡처. 애니메이션·전환·커서 깜빡임을 정지했다.
- 기존 Storybook에서 노출되지 않는 컴포넌트는 비교용 임시 스토리로 렌더링했다. 임시 파일은 커밋에 포함하지 않았다.
- PNG를 디코딩한 RGBA 데이터의 SHA-256과 크기를 비교해 완전 일치를 확인했다. 안티앨리어싱 차이를 무시한 결과가 아니다.
- 대표 화면은 직접 열어 레이아웃, 오버레이, 색상, 글자, 아이콘을 확인했다. 저장한 개요 이미지는 검토용으로 축소·크롭했으며 픽셀 비교에는 원본 전체 화면을 사용했다.
- Firefox·Safari, 실제 모바일 기기, 모든 prop 조합, 실시간 데이터·애니메이션 중간 프레임은 검사하지 않았다.

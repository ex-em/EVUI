# Slider (EvSlider) — Decisions

<!-- 날짜 `-` = SPEC 아키텍처 관찰 기반 초기 결정. -->

| 날짜 | 결정 | 이유 | 대안 |
|------|------|------|------|
| - | 단일값과 범위를 `range` prop + modelValue 타입([Number, Array])으로 단일 컴포넌트 처리 | 슬라이더 UI 를 공유하며 핸들 개수만 다름 | 별도 RangeSlider 컴포넌트(중복) |
| - | color 를 문자열/배열로 허용해 구간별 색상 지원 | 임계 구간 시각화(정상/경고/위험 등) 요구 | 단색 고정(구간 표현 불가) |
| - | 부가 UI(툴팁/입력/눈금)를 클래스 토글로 조건부 렌더 | 옵션별 DOM 을 최소화하고 상태를 클래스로 표현 | 항상 렌더 후 숨김 |

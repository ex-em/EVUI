# Window (EvWindow) — Decisions

<!-- 날짜 `-` = SPEC 아키텍처 관찰 기반 초기 결정. -->

| 날짜 | 결정 | 이유 | 대안 |
|------|------|------|------|
| - | 드래그/리사이즈를 기본 활성(true)으로 | 플로팅 윈도우의 기대 동작이 이동·크기조정이므로 기본 제공 | 기본 비활성(사용자마다 opt-in 필요) |
| - | 크기 단위로 vw/vh/px(문자열)와 숫자 모두 허용 | 뷰포트 비율·고정 픽셀 요구를 모두 수용 | px 고정(반응형 불가) |
| - | 모달/비모달을 `isModal` prop 으로 단일 컴포넌트에서 분기 | 다이얼로그와 플로팅 윈도우가 UI 를 공유 | 별도 컴포넌트 분리(중복) |
